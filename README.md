# Heart-Disease-Project
BY - Samrath Singh Narula
This is my first GitHub project.
In this project, I worked with a Heart Disease dataset to learn and practice the basics of data analysis, data cleaning, visualization, and GUI creation using Python.

The main goal of this project was learning, not perfection.
I wanted to understand how real datasets work and how Python can be used to analyze health-related data in a simple way.
In this project; I have done the following things step by step:
Loaded a heart disease CSV dataset
Cleaned the data (checked missing values, basic formatting)
Performed basic data analysis using pandas
Created visualizations like:
Bar charts
Age group vs heart disease graphs
Boxplots for understanding data distribution
Built a simple GUI using Tkinter
Connected the ML model with the GUI
Displayed results in an easy-to-understand way
This project helped me understand how data, machine learning, and GUI work together.
This project is completely built using Python.

Libraries used:
pandas – for data handling and analysis
numpy – for numerical operations
matplotlib – for visualizations
seaborn – for better graphs 
scikit-learn – for machine learning model
tkinter – for GUI application

I also created a simple graphical user interface (GUI) where:
User can enter basic details
Click buttons to get prediction/output
Buttons are colorful and beginner-friendly
Design is simple and suitable for a college-level project
This helped me learn how machine learning models can be used in real applications.

What I Learned From This Project
Through this project, I learned:
How to work with CSV datasets
How to clean and analyze data
How to visualize data properly
How a machine learning model is trained and used
How to connect backend logic with a GUI
How to upload a project on GitHub properly
